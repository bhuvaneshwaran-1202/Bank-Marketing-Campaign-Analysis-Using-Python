
# Credit Risk Analysis and Loan Default Prediction Using Python

## 1. Project Overview

This project focuses on analysing credit risk and understanding the financial behaviour of loan applicants using Python. The analysis explores customer demographics, annual income, loan amounts, interest rates, employment details and credit history to identify factors associated with loan defaults.

The main objective is to clean and analyse financial data, identify patterns and trends, and generate meaningful insights that can help understand credit risk and loan repayment behaviour.

## 2. Project Objectives

- Load and understand the Credit Risk dataset.
- Perform data cleaning and preprocessing.
- Identify and handle missing values.
- Conduct Exploratory Data Analysis (EDA).
- Analyse customer income and loan distribution.
- Identify factors associated with loan defaults.
- Perform statistical analysis.
- Create meaningful data visualizations.
- Generate conclusions and business insights.

## 4. Dataset Features

The dataset contains the following attributes:

| Column Name | Description |
|---|---|
| person_age | Age of the applicant |
| person_income | Annual income |
| person_home_ownership | Home ownership status |
| person_emp_length | Employment length |
| loan_intent | Purpose of the loan |
| loan_grade | Loan grade |
| loan_amnt | Loan amount |
| loan_int_rate | Loan interest rate |
| loan_status | Loan default status |
| loan_percent_income | Loan amount as a percentage of income |
| cb_person_default_on_file | Previous default history |
| cb_person_cred_hist_length | Credit history length |
